# PropProof

Independent real estate intelligence platform delivering plain-English contract breakdowns, RERA compliance checks, and risk-transparency dossiers for home buyers. 

## About
PropProof is a buyer-aligned advisory platform operating with absolute neutrality and zero developer commissions. 

## Administration & Billing
Billing and administrative operations for the platform are managed by Ruffle Hub Solutions.

## Architecture & Structure
- **Hub Page (`index.html`):** The main storefront featuring the value proposition, active project dossiers, guides, and contact queue.
- **Project Dossiers (`/projects/`):** Dedicated deep-dive pages for specific developments (e.g., Godrej Aveline).
- **Guides (`/guides/`):** SEO-optimized educational resources for homebuyers.

## Hosting
Hosted on **GitHub Pages** and mapped to the custom domain **[propproof.biz](https://propproof.biz)**.
